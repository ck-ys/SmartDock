## ❌ 明确不做

| 不做 | 为什么 |
|---|---|
| 外部网站数据采集（采集脚本 / 前端 SDK / 站点密钥） | 2026-10 已整体移除。数据进系统只有两条路：业务系统调 `ProfileEventPublisher`，离线数据走 CSV 补录。多一条"从外部网站自动抓"的路，口径与合规都会失控 |
| 多智能体自主协同 | 只做 `agentId` 注册与路由，不做 handoff / 团队编排。需要协同请在工厂层自行实现 |
| 开箱即用的 SaaS 成品 | 这是参考实现，不是装上就能用的产品。两条引擎可拆开单独复用，平台基线可直接当脚手架改 |
| 等保 / 隐私 / 行业合规认证 | 仓里只有技术实现，不构成任何合规认证或法律意见 |
| 模型输出的正确性保证 | AI 只负责起草与建议；所有写操作过 HITL 确认，但输出不保证正确，关键结论请保留证据链 |
