# 决策记录索引

这里放的是**设计阶段的决策快照**：为什么改、当时有哪些方案、各自代价是什么、最后选了哪个。

## 先说清楚这是什么、不是什么

- **是**：某个界面/交互/口径在动手前，把多个方案摆出来比较的过程记录。带前后对比图。
- **不是**：需求文档、API 文档、使用指南。当前行为一律以代码与 [路线图](../roadmap.md) 为准。
- **为什么只有这几份**：日常施工过程中的计划草稿、临时脚本、内部环境信息不进入仓库（其中包含内网地址与本机路径）。只有**结论具备长期参考价值**的决策，才会脱敏后归档到这里。

想看「为什么某个口径是这样」而不是「当时讨论了哪几版」，读 [设计取舍](../design-decisions.md)。

## 怎么读

1. 先看每份板开头的「修复前后模拟 UI」——它比文字更快说明改了什么。
2. 再看「问题清单」里你关心的那一题，每题都写了**为什么推荐这个方案**和**代价是什么**。
3. 板里的数字（尺寸、字号、颜色值）是当时的真机实测值，可直接对照当前代码。
