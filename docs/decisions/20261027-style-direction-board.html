诊断：五条「诡异感」的来源（真机对比）

  1. 全白糊成一片：您当前用的是浅色皮肤——侧栏、画布、卡片全是白的，分区只剩 1px 细线，眼睛要费力找边界；DCS 是「深色侧栏 + 浅灰画布 + 白卡片」三层明暗差，边界天然清楚。
  2. 导航没有锚点：DCS 选中的菜单是实心蓝块、白字；我们的是浅蓝药丸、深蓝字，视觉重量弱一档，扫视时找不到「我在哪」。
  3. 整页像浮起来的一张纸：我们的壳是 8px 悬空外卡 + 14px 大圆角 + 双层阴影，1920 宽屏下四周一圈缝很像「没放正的纸」；DCS 内容区贴边、直角、通高。
  4. 底部悬空空白带：已修复 起因是为可拖拽的悬浮球预留 80px；悬浮球本来就哪都能拖（您已把它拖到右侧中部），预留带没有意义，已恢复通高贴底。
  5. 重点信息没有颜色：DCS 的待办 20 用蓝、待审核 91 用橙、待修改 1 用红，扫一眼就知道轻重；我们的关键数字统一深灰，得逐字读。

Q1 壳层方向：三案 待您拍板

方案改什么改完的观感代价 / 风险
甲（推荐）深色侧栏 + 实心蓝选中块 + 灰画布贴边通高（去掉浮卡、大圆角、阴影），卡片圆角统一 12与 DCS 同一骨架，最接近您觉得顺眼的观感壳层 4-5 个文件；等于推翻 10-26 的「外卡悬空」拍板，需要您明说
乙保留浮卡，但换深侧栏 + 实心蓝选中 + 加深画布让白卡浮起来 + 圆角收到 10层次清楚很多，但「浮纸」本身还在改动约为甲的一半；不推翻原结构
丙侧栏保持浅色，只把选中改实心蓝 + 画布微灰 + 圆角 12比现在舒服，但「全白」只是缓解改动最小，1 小时内

甲 · 全面对齐 DCS 骨架 推荐

您的原话是「DCS 看着顺眼」。顺眼的根本原因是它的三层明暗（深栏/灰布/白卡）+ 走边通高 + 实心蓝选中块，这一案就是把它搬回来；同时保留我们自己的令牌体系，以后想换色只动令牌。

代价：改壳层样式与两套皮肤同步，半天内；风险：与上轮「外卡悬空」拍板相反，需您明确同意推翻。

乙 · 保留浮卡，补对比

不动外卡结构，只把导航换回深色 + 选中实心蓝 + 画布加深，让白卡能「浮起来」。

风险：浮卡的「纸感」与四周缝隙还在，1920 宽屏下仍可能与 DCS 观感有差距。

丙 · 最小矫正

侧栏仍是浅色，只改三处：选中实心蓝、画布微灰、圆角 12。改动最小、当天可回滚。

风险：「侧栏无深色锚点」这一主因仍在，观感改善有限。

Q2 关键数字要不要上色 待您拍板

A · 关键数字用语义色（学 DCS）推荐

只给「关键数字与风险状态」上色：蓝=常规重点、橙=待处理、红=风险。不是把全站撒成彩色，只让眼睛先看到该看的。

代价：KPI 与风险表两处样式；风险：颜色用多了会花，需限定在白名单组件内。

B · 保持灰阶

靠字号与字重分层，整体更「安静」。但与 DCS 的观感差距会保留一部分。

风险：重点信息扫描速度慢，与您「看着累」的反馈方向相反。
