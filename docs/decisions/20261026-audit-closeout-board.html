题7 · Schema「校验」按钮说实话 中危 涉前端后端

2026-10-27 活体实测口径（比审计原文更精确）：空着或不是合法 JSON，前端会拦（提示「Schema JSON 不合法」「请先填事件名」）；但只要是一段合法 JSON——哪怕是 {"foo":"bar"} 这种胡写内容——后端一律返回 valid:true，页面亮出绿色「校验通过」。schema 本体根本没进校验：后端只收 props/context/traits 三个字段。 admin.vue:117（前端把 schema 发了过去）；ProfileSchemaController.java:53-56（后端没收它）

真机截图（超管登录）。在哪找：顶部菜单「画像与分析 → 引擎管理」→「协议与 Schema」页签。上半部分是接入协议（含「校验当前协议」，那个是真的验协议）。

真机特写：页面下方的「注册 / 更新 Schema」区——事件名、版本、「校验」「保存」按钮和 Schema JSON 大输入框。出问题的就是这个区的「校验」。

填的是胡写内容，却亮「校验通过」
实测（2026-10-27，真机操作）：
Schema 框填入 {"foo":"bar","这是胡写的":true} → 点「校验」
POST /profile/schema/dcs/validate 返回 {"valid":true,"errors":[]}
页面在按钮旁亮出绿色「校验通过」——schema 本体一个字都没被验。

这不是「没填样本」的问题（空 JSON 有前端护栏），而是校验根本没把 schema 当校验对象：填什么合法 JSON 都绿灯。

止血后：同一份胡写内容将被拦下，如实报「Schema 不合法：缺少 type/properties 等必要结构」（模拟）

真机底图叠加模拟：止血＝让校验真的验 schema 本体（前端本地校验或后端把 schema 字段纳入，约半天），假绿灯当天消失；完整的样本输入重设计仍按留档归批11B。

修复前＝真机截图与真机操作（2026-10-27·5188 演示环境，假绿灯为实拍非模拟）；修复后＝真机底图叠加模拟，落地后换真机复拍。
