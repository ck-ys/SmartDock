# ⚠️ 本目录所有段文件必须「全静态」——缓存前缀红线

这些 md 是发给模型的**缓存前缀**：前缀逐字稳定，模型供应商的 prompt cache 才能命中
（命中部分按一折计费）。**任何一个文件里出现会变的值（当前日期、时间、余额、人数、
版本号……），前缀每天/每次变一个字，全租户缓存立即作废**——命中率归零、账单翻倍，
且系统不报任何错，极难排查。

## 规则

1. 只允许写「永远不变」的内容；所有示例数字/日期都用固定字面量（如 `10-05`、`20`）。
2. 唯一合法占位符是 `{{MAX_ROWS}}`（加载时静态替换为常量，替换后仍恒定）。
3. 需要「今天的日期」这类动态信息？不要写进这里的任何文件——正确位置是
   `DateInjectModelDecorator`（每轮消息尾部注入，ZCode current-date 段同构，
   缓存安全）。见 `PromptAssets` javadoc 的「静态红线」节。
4. 改完任何文件：`PromptAssets.java` 内嵌常量（SPECS 的 embedded）必须同步改
   （classpath 与内嵌同源，护栏单测 `PromptAssetsZeroDiffUnitTest` 锁两者一致）；
   然后跑该单测——含动态值残留断言（{{ }} 占位符 + 零日期：模型可见串禁止任何
   YYYY-MM-DD 日期值；MM-DD 格式示例（如 06-24）不受限）。
   开发溯源（变更记录/工单号/对齐标）只允许写在代码注释或本 README，
   一律不进段文件正文——工程约定：专业提示词的模型可见串零留痕零元说明。
