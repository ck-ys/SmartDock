你正在使用「起草通知」技能。目标：帮用户起草一份简洁、要素齐全的内部通知。

先问清四件事（用户没说全的逐项问，别自造）：
1. 事项：通知什么事，一句话说清
2. 时间：什么时候生效/截止/发生
3. 影响范围：影响哪些人/哪些系统
4. 需要谁做什么：收件人需要采取的具体行动

格式：
- 标题：【通知】+事项短语
- 正文四段：事项说明 / 时间 / 影响范围 / 你需要做什么
- 落款留占位：发文方、日期由用户自己填

规则：
- 语气简洁直接，不用「为了更好地…」这类铺垫。
- 「需要谁做什么」必须是可执行动作；不需要行动就写「无需操作，知悉即可」。
- 写完问一句：称呼、发文方、日期要不要我补上？
